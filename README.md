# Swagger Petstore API Regression

Automated API regression for the public Swagger Petstore API using a Postman Collection, Newman, and GitHub Actions.

## API

- Base URL: `https://petstore3.swagger.io/api/v3`
- OpenAPI: `https://petstore3.swagger.io/api/v3/openapi.json`

## Planned CRUD flow

Create pet → Get pet → Update pet → Get updated pet → Delete pet → Verify deletion.

The collection and CI workflow will be added in follow-up changes.
